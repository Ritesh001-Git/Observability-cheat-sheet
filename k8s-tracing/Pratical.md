# Distributed Tracing with Jaeger, FastAPI & Kind

## 1. What is Distributed Tracing?

Distributed tracing is used to track a request as it moves through an application and its services.

A **trace** represents the complete request, while a **span** represents an individual operation within that trace.

Example:

```text
FastAPI Request
      |
      +-- GET /users
             |
             +-- get-users
                    |
                    +-- database-query
```

Tracing helps identify:

- Where a request spends time
- Which operation is slow
- Where an error occurred
- How different services interact

---

## 2. Jaeger

**Jaeger** is an open-source distributed tracing platform.

In this practical:

```text
FastAPI
   |
   | OpenTelemetry / OTLP
   v
Jaeger
   |
   v
Jaeger UI
```

Important Jaeger ports:

| Port | Purpose |
|---|---|
| `16686` | Jaeger Web UI |
| `4317` | OTLP gRPC |
| `4318` | OTLP HTTP |

For this project, FastAPI sends traces to Jaeger using OTLP gRPC on port `4317`.

---

## 4. Create the Kind Cluster

```bash
kind create cluster --name kind
```

Check:

```bash
kubectl get nodes
```

---

## 5. Load the FastAPI Image into Kind

Build the application image:

```bash
docker build -t fastapi-tracing:v2 ./app
```

Load it into the Kind cluster:

```bash
kind load docker-image fastapi-tracing:v2 --name kind
```

This is important because the Docker image exists locally on the Mac, while the Kind node runs as a Docker container. `kind load docker-image` makes the local image available to the Kubernetes node.

---

## 6. Deploy Jaeger

Create the tracing namespace and Jaeger Deployment/Service:

```bash
kubectl apply -f namespace.yaml
kubectl apply -f jaeger.yaml
```

Check:

```bash
kubectl get pods -n tracing
kubectl get svc -n tracing
```

Expected:

```text
jaeger-xxxxx    1/1    Running
```

---

## 7. Deploy FastAPI

Build and load the image:

```bash
docker build -t fastapi-tracing:v2 ./app
kind load docker-image fastapi-tracing:v2 --name kind
```

Deploy:

```bash
kubectl apply -f fastapi.yaml
```

Check:

```bash
kubectl get pods -n tracing
```

Expected:

```text
fastapi-xxxxx    1/1    Running
jaeger-xxxxx     1/1    Running
```

---

## 8. Access FastAPI

Port-forward the FastAPI service:

```bash
kubectl port-forward -n tracing svc/fastapi 8000:8000
```

Test:

```bash
curl http://localhost:8000/
```

Generate traces:

```bash
curl http://localhost:8000/users
curl http://localhost:8000/orders
curl http://localhost:8000/slow
curl http://localhost:8000/error
```

---

## 9. Open Jaeger UI

Port-forward Jaeger:

```bash
kubectl port-forward -n tracing svc/jaeger 16686:16686
```

Open:

```text
http://localhost:16686
```

Select the service:

```text
fastapi-tracing-demo
```

Then click **Find Traces**.

You should see traces generated by:

```text
GET /
GET /users
GET /orders
GET /slow
GET /error
```

## 11. Useful Troubleshooting Commands

Check all tracing pods:

```bash
kubectl get pods -n tracing
```

Check services:

```bash
kubectl get svc -n tracing
```

Check FastAPI logs:

```bash
kubectl logs -n tracing deployment/fastapi
```

Check Jaeger logs:

```bash
kubectl logs -n tracing deployment/jaeger
```

Check the image used by FastAPI:

```bash
kubectl get pod -n tracing \
  -l app=fastapi \
  -o jsonpath='{.items[0].spec.containers[0].image}'
```

Expected:

```text
fastapi-tracing:v2
```
